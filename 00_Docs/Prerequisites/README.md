# Prerequisites

Everything you need before the course proper. Work through it top to bottom.

## 1. Initial Setup

Get your machine and accounts ready. **[Start with Environment Setup →](./Initial_Setup/README.md)** (install VS Code, run the one-click setup for Git, Python/uv, Node, and Claude Code, then set up your API keys).

Then continue through the numbered guides:

0. [Environment Setup](./Initial_Setup/README.md) — install your tools (**start here**)
1. [Git & GitHub](./Initial_Setup/1_Git_and_GitHub/README.md) — what Git and GitHub are
2. [Set Up Initial Repos](./Initial_Setup/2_Set_Up_Initial_Repos/README.md) — one-time local + remote repo setup
3. [Version Control](./Initial_Setup/3_Version_Control/README.md) — the `upstream` / `origin` / `local` model
4. [Your Weekly Git Workflow](./Initial_Setup/4_Your_Weekly_Git_Workflow/README.md) — the routine you repeat each week
5. [Coding Agents](./Initial_Setup/5_Coding_Agents/README.md) — working with AI coding agents and rules
6. [LLM APIs](./Initial_Setup/6_LLM_APIs/README.md) — the System role and request/response flow

To re-check your environment at any time, see the [setup verification scripts](./Initial_Setup/scripts/README.md).

## 2. The AI Engineer Onramp

Once your environment is ready, start the live sessions: **[The AI Engineer Onramp →](./The_AI_Engineer_Onramp/README.md)** — a 4-week series that prepares you for the AI Engineering Bootcamp.

> ℹ️ _If you don't have experience building end-to-end applications, or you didn't **really** understand [The AI Engineer Challenge](https://aimakerspace.io/aie-challenge) when you completed it, this material may be useful to you. If you're already a senior software engineer, it may not be._
